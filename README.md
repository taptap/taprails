## 中文

### 产品介绍

TapRails 是 TapTap 平台提供的 PC 游戏包体上传工具，用于将游戏包体上传至 TapTap 开发者中心。支持 Windows、macOS 和 Linux 系统，提供命令行界面，支持大文件分片上传。

### 获取工具

请访问 [Releases](https://github.com/taptap/taprails/releases) 页面下载对应操作系统最新版本的工具。

## English

### Introduction

TapRails is a PC game package upload tool provided by TapTap platform for uploading game packages to TapTap Developer Center. It supports Windows, macOS, and Linux systems, provides command-line interface, and supports chunked upload for large files.

### Getting the Tool

Please visit the [Releases](https://github.com/taptap/taprails/releases)  page to download the latest version of the tool for your operating system.
